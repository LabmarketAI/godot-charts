# Visual Asset Gallery

This example displays the procedural chart asset roles in a simple Godot scene.
It is meant for fast visual review of chart marks, structure, and interaction
controls before those assets are placed in the WebXR template.

Run it from a prepared project that contains `addons/godot-charts`, or use the
visual asset test script to build a temporary project and validate the scene:

```bash
GODOT_BIN=/usr/bin/godot scripts/test-visual-assets.sh
```
