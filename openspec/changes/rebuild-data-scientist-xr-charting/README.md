# rebuild-data-scientist-xr-charting

Review the existing addon and define a rebuild path for a data-scientist-first, matplotlib/R-like Godot 3D and XR charting library.

Implementation begins with **Milestone M1: Architectural Spine** in `tasks.md`: a deterministic recorded Python-originated scatter plot and bounded table rendered in clean standard Godot with stable row identity, linked inspection/selection, incremental replacement, diagnostics, provenance, and automated public-contract tests. Broader transports, live Jupyter authentication, additional chart families, geospatial integrations, and WebXR follow only after the M1 exit review.
